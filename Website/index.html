    Public IPv6 is deliberate

    Public IPv6 must match an allocated global-unicast prefix from the bundled corpus and lie outside special-purpose ranges. Membership in 2000::/3 alone does not grant access.

    Mapped addresses keep IPv4 rules

    ::ffff:192.168.1.1 is classified by the embedded IPv4 address. An IPv6 representation cannot bypass IPv4 deny rules.

    Special purpose stays special

    The public profile blocks special-purpose allocations even where IANA marks them globally reachable. “Routable” does not make an address an appropriate HTTP target.

    DESIGN BOUNDARIES

    One extension. Explicit trust.

    Browser policy simulation for netresearch/typo3_http_guard. Address rules come from the repository’s versioned corpus.

    Policy simulation
    01

    Normalize before deciding

    HTTP(S), an exact authority and a valid port. Reject userinfo, fragments, zone IDs, Unicode hosts, numeric shortcuts and ambiguous syntax. A single final DNS dot is normalized.

    02

    Deny rules have priority

    Operator denies and immutable special-purpose blocks cannot be overridden. The public client only permits ordinary public unicast. No first-match-wins behavior.

    03

    Grant a client, not a URL

    An internal exception binds a trusted client to an exact scheme, host, port, method set and narrow IP set. The endpoint selector here simulates that trusted binding; a user-selectable string must never grant it in production.

    04

    Check the whole answer set

    Every usable A and AAAA answer must pass. Missing, invalid or excessive answers fail closed. A grant cannot turn a hostname into a trusted destination.

    05

    Transport completes the protection

    The extension requires controlled cURL, DNS pinning, isolated transfers and fresh checks for redirects and retries. Those transport guarantees are outside this browser simulation.

    06

    Keep the scope intact

    The product is netresearch/nr-http-guard, an independent TYPO3 extension. nr-vault and nr-llm are references only. Adapters, migrations and changes to either project are out of scope.
