## Security findings and fixes

1. **Policy failure could be retried by an indiscriminate project decider.** The earlier terminal rejected a synchronous or lazy policy failure without revoking its live invocation, allowing middleware that retries every rejection to seek another plan. The transport owner reproduced a failing regression, then closed the invocation on synchronous `PolicyException` and observed lazy policy rejections before the retry chain. [TerminalGuardMiddleware](../../packages/http-guard/src/Transport/TerminalGuardMiddleware.php) and `testPolicyFailureCannotBeRetriedEvenByIndiscriminateMiddleware()` in [ProductionTransportTest](../../packages/http-guard/tests/Integration/ProductionTransportTest.php) record the repair. A retry decider excluding policy exceptions was insufficient evidence for the guard invariant.

2. **An external provider could place project middleware before the boundary.** Boundary-before-terminal and terminal-last checks alone permitted an origin rewrite before authority/context capture. The factory now requires the actual source-matched stock Guzzle prefix, then permits only the exact Core allowed-host middleware at the documented position. Project middleware must follow the boundary. [GuardedClientFactory](../../packages/http-guard/src/Client/GuardedClientFactory.php) and `testExternalProviderCannotPutProjectMiddlewareBeforeBoundary()` prove rejection. Guzzle 7 has four default entries and Guzzle 8 five; the comparison uses the exact runtime class name without introducing a framework symbol dependency into the standalone package. The final actual four-cell Core matrix passes this frozen source.

3. **Raw URI information was lost before policy validation.** An empty fragment marker is erased and a backslash is encoded by the URI constructor. Middleware cannot recover either original string. The TYPO3 package now decorates the real Core raw-string RequestFactory entry, validates before construction, selects the exact Core-13/non-readonly or Core-14/readonly ABI and checks competing registrations. Diagnostic policy-check does the same. Enforce rejects before HTTP; observe reports would_deny and delegates unchanged; disabled is transparent. Actual Core/DI/PSR-17 identity, raw denial and original unprotected conversion are covered by the [Core evidence](../typo3-integration/README.md) and unit raw-mode red/green record.

4. **Vault OAuth still constructed a request before checking its raw endpoint.** The adapter owner added `guardValidateRawUri()` / `validateRawUri()` before OAuth request construction and credential lookup. The inspected working source preserves observe/disabled behavior and rejects enforce before credentials/contact. The source-bound Guzzle-8 run passed 18 tests / 205 assertions, including empty-fragment and backslash variants. A further read-only pass verified the frozen shared-corpus case uses its exact input and actual inner terminal driver, zero native/lease counts, unchanged target TCP/HTTP and a never-retrieve credential expectation; its final execution is assembled by that owner. Final patch/source-overlay and Guzzle-7 evidence must use their refreshed manifests. Resource send APIs receive PSR requests and cannot independently recover raw syntax; callers must validate raw resource strings before construction.

## Integration and operational findings

Doctor originally checked only part of the native capability tuple. It now invokes the shared runtime support check and reports missing curl-multi, exact dependency families and real process proxy variables without target HTTP. Overdue endpoint reviews are warnings, not automatic denial. The default OS DNS configuration is now loaded only at an actual DNS query. The final Core CLI cases and policy tests cover those fixes.

The actual flat/nested legacy distinction was initially covered only by a unit. The final genuine fixtures include flat `HTTP.allowed_hosts[0]='erp.test'` alongside Core contexts; all four cells show `address_forbidden` and unchanged TCP/HTTP counters for its unbound Public request. This closes the identified T039 integration evidence gap. Each cell also consumes the shared `EP-PRIVATE-UNBOUND` case by ID/hash, rather than copying it into a parallel fixture definition.

Vault observe/disabled custom resolver preservation requires explicitly supplying the original configured legacy factory. The outer opted-in factory's resolver is not propagated automatically. This is now stated in the adapter owner's documentation and demonstrated by its real mode-control fixtures. A fresh default legacy factory preserves the normal default resolver case only.

Immutable policy snapshots are intentional under the original operations contract. Deployment/cache rebuild and controlled worker replacement activate changed policy. Cross-registry context rejection is not evidence of live revocation of an already-built client. The delivery documentation now makes that lifetime distinction explicit. Request-owned Guzzle handlers execute before middleware entry and remain outside T077 coverage; public PSR-18/typed PublicFetch APIs do not expose such an option.
