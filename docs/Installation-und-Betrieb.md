# Installation und Betrieb

Die vollständige Anleitung gehört jetzt zur einen TYPO3-Extension und liegt
unter [Documentation/Installation](../Documentation/Installation/Index.rst),
[Konfiguration](../Documentation/Configuration/Index.rst) und
[Betrieb](../Documentation/Operations/Index.rst).

Sie wird im installierbaren Extension-ZIP mitgeliefert. Es gibt keine
zusätzliche HTTP-Guard-Bibliothek zu installieren. Die ursprüngliche
Anleitung für zwei Pakete wird ausschließlich als historischer
Entwicklungsnachweis unter `evidence/design-history/` bewahrt.
